## ============================================================================
## ARCHITECTURE
## ============================================================================

CloudDestroyer DB (Scraping Service)    FoodFinder DB (Consumer App)
├── scraping_jobs                       ├── restaurants
├── scraping_results         ────►      ├── menu_items
├── scraping_workers                    ├── menu_categories
├── scraping_job_history                ├── chain_configs
├── scraping_templates                  ├── search_queries
├── target_sites                        ├── popular_searches
├── system_config                       ├── user_interactions
└── health_checks                       └── app_config

Sync Flow:
1. CloudDestroyer extracts menu data → scraping_results
2. Sync procedure (or Python worker) reads pending results
3. Data transformed and inserted into FoodFinder tables
4. Result marked as synced in CloudDestroyer
